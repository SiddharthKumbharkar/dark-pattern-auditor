HOW TO USE THIS PAYLOAD
========================
Role:       coordinator

1. Open prompt.txt and copy its full contents into your LLM chat as the
   system/first message.
2. Attach evidence_summary.json (as a file, or paste its contents) as the
   evidence payload.
3. Attach every image under screenshots/ -- their filenames match the
   step_id mapping listed in prompt.txt and in manifest.json's
   "screenshot_step_mapping".
4. response_schema.json documents the EXACT JSON shape the model's reply
   must match. Ask the model to return ONLY that JSON (prompt.txt already
   says this too, but repeat it if your interface strips instructions).
5. When you have the model's response, save it as response.json in THIS
   SAME DIRECTORY.

To fold this response into the stored episode, run:
  python3 ingest_response.py <episode_id> --role coordinator --file response.json --model "<model name>" --operator "<your name>"
This validates the response against response_schema.json and writes it into episode.mechanism_verdict.entries alongside model_name/prompt_version/ingested_at/operator. Then run:
  python3 build_output.py <episode_id>
to compute overall_verdict/coverage/top_findings/summary -- those are generated from episode.attributes.results wholesale, not part of this response, so build-output must run (and re-run after any later re-ingest) for them to reflect this pattern_combinations pass.
